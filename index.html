기획 배경

마인크래프트 '인생서버'를 운영하며 플레이어들과 아프리카티비 생방송을 함께 진행하였습니다. 재료 가격과 토지 면적에 대한 불만을 듣고 가격을 조정하고 면적 제한을 늘린 결과, 플레이어들의 이용 시간이 늘어났습니다. 이 경험을 계기로 플레이어끼리 교류하고 거래하는 게임을 기획하게 되었습니다.

핵심 설계

  • 생활 직업 하나와 전투 직업 하나를 함께 키우는 이중 직업 구조입니다.
  • 캐릭터 레벨 대신 무기와 스킬의 숙련도가 성장합니다.기획
  • 고용 상인을 원하는 위치에 배치하여 다른 플레이어와 거래합니다.기획
  • 같은 테이블에 앉은 플레이어끼리 서로 승낙하면 음성 통화가 가능합니다.기획

  • 클로드가 유니티와 블렌더를 직접 제어하여 코드와 3D 작업을 수행합니다.
  • 코덱스 CLI로 타이틀 화면 인물과 메뉴 아이콘을 제작하여 게임에 적용하였습니다.
  • 직업별 캐릭터 대사는 AI 음성으로 제작하였습니다.
  • 저는 방향을 정하고, 결과를 사진과 영상으로 검수한 뒤 다시 지시하는 역할을 맡았습니다.

청약 공고 PDF를 AI가 분석하여 회원 조건과 대조해 주는 웹 서비스입니다.

기획 배경

SH 공고를 확인하는 과정에서, 지원 가능 여부와 순위를 알기 위해 수십 쪽 분량의 PDF 공고문을 직접 읽어야 한다는 점이 불편하였습니다. 청년인 저에게도 번거로운 일이라면, 어르신이나 처음 청약을 접하는 분들에게는 더 큰 장벽일 것이라고 생각하였습니다.

핵심 기능

  • 공고 주소를 붙여 넣거나 PDF 파일을 끌어 놓으면 분석을 시작합니다.
  • 신청 가능 여부, 예상 순위, 필요 서류를 정리합니다.
  • 전체 공고 중 조건에 맞는 세 곳을 같은 기준으로 비교합니다.
  • 계약 준비금과 이번 달 생활비를 함께 계산합니다.
  • 공고가 정정되거나 회원 정보가 바뀌면 자동으로 다시 계산하고 달라진 항목을 표시합니다.

AI 활용

AI가 공고문을 읽고 가입 시 입력한 회원 정보와 대조합니다. LH · SH 등 청약 공식 API를 연동하여 전국의 공고를 한곳에서 조회할 수 있도록 구성하였습니다.

남은 과제

AI가 공고 내용을 잘못 판독하는 경우를 막는 확인 장치가 필요합니다. 또한 어르신 등 실제 이용자를 대상으로 사용성을 검증해야 합니다.

선행 시험

실제 상품

기획 배경

키캡 · 키링 액세서리 브랜드 '도리링'의 판매를 준비하고 있으며, 실제 키캡 36종의 상품 사진을 갖추었습니다. 상품을 등록해 두는 것만으로는 눈에 띄기 어렵다고 판단하여, 게임 제작 경험을 살려 상품을 게임으로 먼저 경험하게 하는 방식을 기획하였습니다.

AI 활용

실제 상품인 핑크 체리 키캡을 바탕으로, 눌리기 전과 눌린 뒤의 그림 두 장을 AI로 제작하였습니다. 아래 몸통은 고정되고 위의 키캡만 눌리도록 맞추어, 실제 키보드를 누르는 느낌을 살렸습니다. 게임 부분은 윈드플래닛의 채집 · 합성 구조를 작게 줄여 활용할 계획입니다.

남은 과제

실물을 무료로 보내 주는 구조에서 수익을 남기는 방법을 구체화해야 합니다. 재미를 만드는 부분은 게임 제작 경험으로 준비되어 있으나, 판매로 이어지는 구조는 검증이 필요합니다.

실시간 만남 앱

같은 공간에 있는 사람과, 서로 원할 때만 이어지는 만남 앱입니다. 만남 앱에 대한 부정적인 인식을 고려해 안전하고 깨끗한 이미지를 중심으로 구상하였습니다.

근처 카페에서 책 읽는 중

  1. 위치 공개 켜기원할 때만 켜고, 켠 사람끼리만 서로 보입니다
  2. 지도에서 프로필 사진 확인같은 앱을 설치하고 켠 사람만 프로필 사진으로 표시 · 미설치자는 표시되지 않습니다
  3. 프로필 확인누르면 MBTI · 자기소개 등 간단한 정보 확인
  4. 포인트로 메시지 신청마음에 들면 포인트를 사용해 메시지 신청
  5. 수락 후 대화 · 실시간 만남서로 수락하면 대화하고, 식당 · 거리 등 지금 있는 곳에서 만남

위 시안의 프로필 사진을 누르면 아래 정보가 바뀌고, '메시지 신청'과 '위치 공개' 단추도 눌러 볼 수 있습니다. 인물은 예시입니다.

기획 배경

사회에서 새로운 사람을 자연스럽게 만나기 어려운 사람이 많지만, 기존 만남 앱은 앱 안에서 프로필을 둘러보는 데 그칩니다. 식당이나 거리처럼 지금 같은 공간에 있는 사람에게 앱을 통해 직접 다가갈 수 있는 방식을 생각하였습니다.

깨끗한 이미지를 위한 설계

  • 가입 시 성범죄 이력을 확인합니다.
  • 매일 위치가 보이는 부담을 줄이도록 위치 공개를 직접 켜고 끕니다.
  • 가입 시 프로필 사진 등록을 필수로 하여, 지도에는 항상 사진으로 표시됩니다.
  • 앱을 설치하지 않은 사람은 지도에 표시되지 않고, 서로의 프로필도 볼 수 없습니다.
  • 성인 인증 · 차단 · 신고 기능을 둡니다.

지도 연동

네이버 · 카카오 지도 API를 앱 안 지도로 가져와, 앱을 켠 이용자가 근처를 지나가면 게임 속 다른 플레이어처럼 프로필 사진이 지도 위에 움직이도록 구상하였습니다.

남은 과제

  • 위치 정보를 다루기 위한 위치기반서비스 사업 신고 등 법적 절차
  • 성범죄 이력을 확인할 수 있는 법적 범위 검토
  • 실시간 위치 표시에 따른 안전 장치
공통

AI 작업 방식

코딩을 배우지 않은 상태에서 시작하여, 개발이 막힐 때마다 도구와 작업 방식을 바꾸어 왔습니다.

  1. 1RPG 쯔꾸르 · 펑크랜드

    도구 기능의 한계로 개발을 중단하였습니다.

  2. 2챗지피티

    코드를 받아 붙여 넣는 방식은 규모가 커질수록 오류가 쌓였습니다.

  3. 3코덱스

    AI가 파일을 직접 수정하고, 데이터를 엑셀로 정리해 다시 넣는 것을 확인하였습니다.

  4. 4클로드

    코드 작업의 중심을 옮기고, 2D 도트 게임을 3D로 전환하였습니다.

  5. 5클로드 + 코덱스 CLI

    코덱스의 이미지 생성 기능을 클로드에 연결하여 하나의 작업 흐름으로 묶었습니다.
